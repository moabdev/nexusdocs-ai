# Velox Logistics Knowledge Base

Synthetic enterprise knowledge base created for the development, testing and evaluation of NexusDocs AI.

## About Velox Logistics

Velox Logistics is a fictional logistics company operating transportation, delivery and tracking services for businesses and consumers.

The company manages regional distribution centers, delivery operations, shipment tracking, customer claims and an internal technology platform.

This knowledge base intentionally contains:

- versioned corporate policies;
- superseded documents;
- information distributed across multiple documents;
- operational procedures;
- frequently asked questions;
- technical documentation;
- structured operational data;
- metadata for document governance.

These characteristics are designed to reproduce common enterprise knowledge retrieval challenges.

## Purpose

The dataset is used to develop and evaluate capabilities such as:

- document ingestion;
- semantic search;
- metadata filtering;
- hybrid retrieval;
- reranking;
- version-aware retrieval;
- multi-document reasoning;
- source attribution;
- structured data analysis;
- grounded answer generation;
- RAG evaluation.

## Important

All companies, policies, procedures, employees, operational metrics and business data contained in this knowledge base are fictional and were created exclusively for software development and evaluation purposes.
